About StockPredict AI

Intelligent stock price prediction using Machine Learning

What is StockPredict AI?

StockPredict AI is a machine learning based stock price prediction system designed to analyze historical stock market data and predict future stock prices.

The system uses historical Open, High, Low, Close and Volume data to train a Linear Regression model and generate price predictions.

Technology Used

Python – Backend programming and machine learning.

Flask – Web application framework.

MySQL – Database management.

Pandas & NumPy – Data processing.

Scikit-learn – Machine learning model.

Chart.js – Data visualization.

HTML & CSS – Frontend interface.

Machine Learning Model

The system uses Linear Regression for stock price prediction.

The model is trained using historical stock features such as Open Price, High Price, Low Price and Volume.

Model performance is evaluated using MAE, MSE, RMSE and R² score.
